Stage 01 Pending
Disk Drive Status
Queries hardware-level status of all connected disk drives. Expects "OK" for each drive listed. Any other value indicates a potential hardware failure.
C:\>wmic diskdrive get status
✓ Good result: All entries show OK
⚠ Caution: Any value other than OK — back up data immediately and research the status code online.
✗ Bad result: Pred Fail means imminent drive failure.
Stage 02 Pending
Filesystem Light Scan
Runs a non-destructive filesystem check. Reports errors found without attempting to fix them. Safe to run on a live system.
C:\>chkdsk C: /scan
✓ Good result: "Windows has scanned the file system and found no problems."
⚠ Caution: If errors are found, proceed to the deep scan in the Final Actions section below.
Stage 03 Pending
System File Verification
Scans all protected Windows system files for corruption and attempts automatic repair using cached copies. This can take 10–20 minutes.
C:\>sfc /scannow
✓ Good result: "did not find any integrity violations"
⚠ Found & fixed: "found corrupt files and successfully repaired them" — run DISM next (Stage 5).
✗ Could not repair: Run DISM first, then re-run SFC.
Stage 04 Pending
Drive Defragmentation
Analyses and defragments drive C: with verbose output. Skip this if your C: drive is an SSD — Windows handles SSD optimisation automatically and manual defrag can reduce its lifespan.
C:\>defrag C: /u /v
✓ HDD only. Progress shown in real time with /u. Verbose report printed after.
⚠ SSD users: Skip this stage entirely — Windows 10/11 auto-optimises SSDs weekly.
Stage 05 Pending
DISM Image Scan
Uses the Deployment Image Servicing tool to check the Windows component store for corruption. More thorough than SFC — can repair files that SFC cannot.
C:\>DISM /Online /Cleanup-Image /ScanHealth
✓ Good result: "No component store corruption detected."
✗ Corruption found: Run DISM /Online /Cleanup-Image /RestoreHealth to repair, then re-run SFC.
Final Actions
Deep Filesystem Repair
Schedules a full chkdsk with automatic fix (/f) and bad sector recovery (/r) on next reboot. Only run this if Stage 2 found errors. Takes 1–3 hours at startup.
C:\>chkdsk C: /f /r
C:\>DISM /Online /Cleanup-Image /RestoreHealth
Scheduled Restart
If a deep scan or chkdsk was scheduled, restart Windows. A 100-second countdown is shown. Ensure all work is saved before running.
C:\>shutdown /r /t 100 /c "Scan reboot"
