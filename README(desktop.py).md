Runs the commands directly — no copy-pasting needed.

Requirements

Python 3.8 or newer (https://python.org)
Windows 10 or 11
No extra pip installs — uses only the standard library
Usage

Right-click sysguard_desktop.py → Open with → Python OR open a terminal and run: python sysguard_desktop.py
Right-click the terminal → Run as Administrator for full access
Click individual stage buttons or "RUN ALL STAGES"
Output streams live in the right panel
Features

Live command output streamed in real time
Run all 5 stages sequentially with one click
Final Actions: deep repair, DISM restore, restart, abort restart
Admin status detected on launch
